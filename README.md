# Ubah Nama Secara Massal File dengan PowerShell
Mengubah nama file sekali jalan dalam suatu folder menggunakan powershell

Script ini akan:

Mengambil angka di depan nama file.\
Mengubahnya menjadi 2 digit (01, 02, dst.).\
Memindahkannya setelah kata doa.\
Mengganti nama file, misalnya:\
1_doa_tidur_terjemah_.mp3 → doa_01_tidur_terjemah_.mp3\
10_doa_bepergian_terjemah_.mp3 → doa_10_bepergian_terjemah_.mp3\


Jalankan script tersebut di folder tempat file-file MP3 berada.
